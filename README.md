# KrasGuessr

Веб-игра с картой Красноярска и возможностью создавать и редактировать локации.

## Запуск

1. Получите API-ключ для Яндекс.Карт с доступом к JavaScript API 2.1. (https://yandex.ru/dev/jsapi-v2-1/doc/ru/)
2. Скопируйте файл `web/config.example.js` в `web/config.js`.
3. Откройте `web/config.js` и замените `YOUR_API_KEY` на свой ключ:

   ```js
   window.YANDEX_MAPS_API_KEY = "YOUR_API_KEY";
   ```

4. Запустите `start.bat`.

Игра лучше работает с российских IP-адресов.
Работа некоторых функций может быть затруднена по независящим от нас причинам. Допускается снижение скорости загрузки изображений из-за нарушений работы ЦОД Яндекс

Также можно открыть `web/index.html` через локальный веб-сервер. Для работы редактора используйте `web/editor.html`.
